# CT-VAM Project Page

This is a static project page for:

**CT-VAM: A Cerebello-Thalamic-Inspired Vision-Action Model for Efficient Visuomotor Control**

## Deploy with GitHub Pages

1. Copy the contents of this folder into the repository root of `embodied-ai-research/ct-vam`.
2. Commit and push to `main`.
3. In GitHub, open `Settings -> Pages`.
4. Select `Deploy from a branch`, choose `main`, and set the folder to `/root`.

The default URL should be:

`https://embodied-ai-research.github.io/ct-vam/`
